# BMI 분석기

키와 몸무게를 입력해 체질량지수(BMI)와 성인 기준 구간을 확인하는 간단한 웹 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도의 설치나 서버가 필요하지 않습니다.

## 사용 안내

키는 cm, 몸무게는 kg 단위로 입력합니다. 결과에는 BMI, 한국 성인 BMI 구간, 정상 BMI 구간에 해당하는 참고 체중 범위가 표시됩니다.

이 결과는 성인 대상의 일반적인 참고 정보이며 의료 진단을 대신하지 않습니다. 성장기 아동·청소년, 임신 중인 사람 등에게는 이 기준을 적용하지 마세요.
